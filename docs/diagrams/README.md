# Diagrams and media

Source files and generated assets for the diagrams used in `README.md`, the governed docs, and
external write-ups.

## What lives here

| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `img/star-score-curve.svg`                               | The star-count bell curve — 12 buckets as bars against the continuous Gaussian, hidden-gem band 3–7. |

Both scoring SVGs are hand-authored rather than generated by a charting library, so they inherit the
dashboard's palette and stay legible at LinkedIn/README widths. They are referenced from the "How
scoring works" section of the root `README.md`.

## Converting a screen recording to a GIF

`output.gif` was produced from `input.mp4` with:

```bash
ffmpeg -i input.mp4 -vf "fps=15,scale=640:-1,tpad=stop_mode=clone:stop_duration=3" output.gif
```

Used for the LinkedIn post about the scoring algorithm (draft in `docs/linkedin-scoring-post.md`).

Why each part matters, since the defaults are wrong for this:

- `fps=15` — drops from the source frame rate. GIF has no interframe compression worth the name, so
  frame count drives file size almost linearly.
- `scale=640:-1` — fixes the width and lets the height follow the source aspect ratio. 640px is
  wide enough to read UI text in a LinkedIn feed without inflating the file.
- `tpad=stop_mode=clone:stop_duration=3` — holds the **final** frame for 3 seconds. A GIF loops
  forever with no pause, so without this the last frame is gone before it can be read and the loop
  point looks like a glitch. `clone` repeats the last frame rather than padding with black.

Re-run it from this directory after replacing `input.mp4`.
