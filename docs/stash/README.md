# Stash — research notes

One file per investigated idea, written by `idea-discovery` (`/idea-discovery`) and only when the
user explicitly says to record it. Each note is linked from a one-line entry in
[docs/ideas.md](../ideas.md).

**These are research notes, not decisions.** A note carries a status banner saying so. Nothing in
this directory is a spec the code must satisfy — that is what `docs/prd.md`,
`docs/architecture.md`, `docs/project-management.md` and `docs/adr/` are for, and only `idea-triage`
writes those.

Naming: `<short-kebab-slug>.md`, named for the finding rather than the input that prompted it
(`postgres-fts-vs-pgvector.md`, not `that-hn-thread.md`).
